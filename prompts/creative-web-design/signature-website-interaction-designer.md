# Signature Website Interaction Designer

## 🎯 Overview
Use this as a later-stage creative enhancement prompt once the foundational site already exists. It introduces a single cohesive signature interaction or structural transition that elevates the experience from competent to unforgettable without feeling bolted-on.

## 📋 Prompt
```text
Add **[SIGNATURE INTERACTION / STRUCTURAL IDEA]**.

It should feel like a natural consequence of the existing website rather than an effect pasted on afterward.

Integrate it into the current visual language, motion system, and narrative.

Do not redesign everything around it unless necessary.

Example:

Add an infinite scroll: a final section that morphs smoothly back into the opening scene.

The transition should feel continuous enough that the end and beginning become part of the same experience.

Then **[PUBLISH / DEPLOY / EXPORT / CREATE ARTIFACT]**.
```

## 🧩 Variables & Placeholders
| Variable | Description | Example |
| :--- | :--- | :--- |
| `[SIGNATURE INTERACTION / STRUCTURAL IDEA]` | The bespoke mechanical or motion concept | `Cursor-coupled magnetic lens distortion over gallery items` |
| `[PUBLISH / DEPLOY / EXPORT / CREATE ARTIFACT]` | Target delivery action | `Update the standalone HTML artifact` |

## 💡 Example

### Example Usage
```text
Add an infinite scroll: a final section that morphs smoothly back into the opening scene. Then publish it as an artifact.
```

### Why This Is a Useful Example
This demonstrates a **signature structural interaction**, rather than simply adding decorative animation.

The important idea is not specifically "infinite scroll."

The reusable technique is:

1. Let the main website exist first.
2. Identify whether the experience is visually competent but lacks a memorable structural idea.
3. Introduce one strong mechanic that changes how the experience behaves or resolves.
4. Integrate that mechanic into the existing narrative and motion language.
5. Avoid stacking many unrelated effects on top of the site.

Why the example works:
- The end of the website becomes connected to the beginning.
- The experience forms a continuous loop instead of ending like a conventional page.
- The interaction affects the site's structure, not just its decoration.
- It creates a memorable transition using one understandable idea.
- It can be integrated after the primary design already exists.

Different projects should use different signature mechanics depending on their concept.

For example, another project might use mechanics such as:
- the final object disassembles into the opening typography
- content accumulated during scrolling assembles into the final scene
- the last section rotates or transforms into the hero
- one persistent object travels through every section and resolves at the end
- earlier sections collapse into a single final object
