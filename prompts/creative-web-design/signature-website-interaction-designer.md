# Signature Website Interaction Designer

## 🎯 Overview
Use this as a later-stage creative enhancement prompt once the foundational site already exists. It introduces a single cohesive signature interaction or structural transition that elevates the experience from competent to unforgettable without feeling bolted-on.

## 📋 Prompt
```text
Add **[SIGNATURE INTERACTION / STRUCTURAL IDEA]**.

It should feel like a natural consequence of the existing website rather than an effect pasted on afterward.

Integrate it into the current visual language, motion system, and narrative.

Do not redesign everything around it unless necessary.

Example:

Add an infinite scroll: a final section that morphs smoothly back into the opening scene.

The transition should feel continuous enough that the end and beginning become part of the same experience.

Then **[PUBLISH / DEPLOY / EXPORT / CREATE ARTIFACT]**.
```

## 🧩 Variables & Placeholders
| Variable | Description | Example |
| :--- | :--- | :--- |
| `[SIGNATURE INTERACTION / STRUCTURAL IDEA]` | The bespoke mechanical or motion concept | `Cursor-coupled magnetic lens distortion over gallery items` |
| `[PUBLISH / DEPLOY / EXPORT / CREATE ARTIFACT]` | Target delivery action | `Update the standalone HTML artifact` |

## 💡 Example
### Input
```text
Add a seamless camera zoom transition where clicking any portfolio tile smoothly deepens the perspective into the project case study with zero hard page reload.
```

### Expected Output
Clean implementation code integrating state management, CSS/WebGL animation timing, and accessible fallbacks preserving the existing page layout.
