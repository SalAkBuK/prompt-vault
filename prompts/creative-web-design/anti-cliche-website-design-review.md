# Anti-Cliché Website Design Review

## 🎯 Overview
Use this as a second-pass design review prompt after a site is functionally sound but feels predictable, templated, or obviously AI-generated. The `[UNWANTED PATTERN]` entries are intentionally editable placeholders so you can target whichever specific AI design tropes have emerged in your build.

## 📋 Prompt
```text
Review the current design and remove or redesign any elements that make it feel generic, templated, or obviously AI-generated.

Do not use:

- [UNWANTED PATTERN]
- [UNWANTED PATTERN]
- [UNWANTED PATTERN]
- [UNWANTED PATTERN]

For this version specifically:

No "01/03" counters, eyebrow labels, monospace text, or long thin decorative lines.

Do not simply delete them and leave empty holes. Solve the hierarchy, navigation, pacing, and composition in a more original way.
```

## 🧩 Variables & Placeholders
| Variable | Description | Example |
| :--- | :--- | :--- |
| `[UNWANTED PATTERN]` | Specific visual cliché or repetitive trope to forbid (editable list) | `Bento grid cards with gradient borders`, `Floating pill tags with glowing dots` |

## 💡 Example
### Input
```text
Review the current design and remove or redesign any elements that make it feel generic, templated, or obviously AI-generated.

Do not use:
- Dark mode glassmorphism cards with purple neon glows
- Centered 3-column feature cards with generic SVG icons
- Floating pill badges reading "FEATURE 01"
- Center-aligned hero buttons with glowing outer rings
```

### Expected Output
A sophisticated critique and redesign proposal that restructures the page with organic whitespace, varied rhythm, asymmetric balance, and authentic editorial layout without empty holes.
